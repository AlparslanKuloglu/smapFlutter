## Architecture
- Feature-first MVVM with stacked; get_it with a `session` scope; auto_route (`XxxView` → `XxxRoute`); dart_mappable DTOs;
  repositories return `Either<AppException, T>`; one `NetworkService` (Dio). No new Provider/ChangeNotifier screens.
- Screen = `lib/features/<f>/presentation/<screen>/{<screen>_view.dart, <screen>_viewmodel.dart, widgets/ (part files), sheets/}`.
- Pure logic in `lib/features/<f>/application/` (unit-tested). Domain constants stay in their feature, never in `core/`.
- ViewModels are context-free: navigation via injected `AppRouter`, toasts via `ToastText` lambdas, sheets via `XSheet.show()`.
  VMs are never registered in get_it; services are injected from `locator` in `viewModelBuilder`.
- Legacy code (`lib/views`, `lib/repository`, `lib/http_service`, Provider screens) is migrated screen by screen (strangler).
  New code never reads legacy Providers. **Do not delete a legacy feature that works against the real backend unless your task
  explicitly replaces it** (owner rule). Only dead, unreachable, mock or "coming soon" code may be removed, with grep evidence.

## UI rules
- Colors only via `context.appColors` (SmapColors); text only via `context.appText` (SmapText) + `copyWith(color:)`;
  spacing via `AppSpacing`/MihrSpacing; radius via `AppRadius`; motion via `context.motion(...)`/`SmapDurations`; icons via `phosphor_flutter`.
- Forbidden in features/shared UI: `Color(0x…)`, `Colors.*`, `TextStyle(`, `fontSize:`, mihr color/typography getters, `Icons.*`,
  `CupertinoIcons.*`, raw `Duration(...)`, string literals in `Text`, `showDialog`/`AlertDialog`/`showModalBottomSheet`/`SnackBar`,
  `MaterialPageRoute`, `Navigator.push`, `SharedPreferences.getInstance`, `print(`.
- Orange only for the camera button, position indicator, progress and "today". Selection is navy. No white text on orange.
- Cards: no border, no shadow. Blur only on the bottom bar and sheet scrim. Plain rounded corners (no squircle).
- Build from `lib/shared/ui` (`App*`) and feature widgets. Spec names `SmapX` map to `AppX` (generic) or `X` (domain). Keep the
  spec C-number in the doc comment. A missing generic piece goes to `shared/ui` + its gallery page in the same task.
- Class widgets only (no `Widget _buildX()`). Private `_Widgets` in part files, const constructors, one section per part file.
  Limits: view shell ≤ 250 lines, part ≤ 300, VM ≤ 500, no presentation file > 400.
- Root view is `StackedView` with `reactive => false`; each data section is a `SelectorViewModelWidget` with a record selector over
  immutable values; actions via `getParentViewModel(context, listen: false)`; fast-changing values via `ValueNotifier`.
- One `CustomScrollView` per screen (`PinnedHeaderSliver`, `SliverMainAxisGroup`). No `NestedScrollView`, no `sliver_tools`.
- Every section has loading (skeleton mirroring the layout, 15 s timeout), empty, error and offline states. Never render fake data;
  if data is missing, do not draw the field. Features waiting on backend sit behind flags (spec §6.4).
- All dialogs are `AppSheet` sheets returning a typed result; the calling VM writes, toasts and undoes.
- mihr_ui dev.3 buttons: pass `tapTargetSize: MaterialTapTargetSize.padded` per instance; avoid theme-level `styleBuilder` overrides.
- Copy: "Vazgeç" (never "İptal"), "Tamam", "Kapat" (a11y only), "Geri Al" (toast only); "sen" tone; no emoji; no ALL CAPS;
  question titles sentence case, screen/sheet titles Turkish title case. Numbers/dates only via `TrFormat` (67,5 · 412,63 · 48.215 · %42 · 5 Eki.).
- l10n: keys `<feature>_<camelCase>`, shared `common_*`, screen-reader-only `…A11y`. Turkish-aware case folding (`TurkishText`);
  never `toUpperCase()` on Turkish text.
- Accessibility: 48 dp targets; `semanticLabel` + tooltip on icon buttons; single Semantics reading for D/Y/B and question cells;
  header semantics on titles; `liveRegion` for status; text scale 1.3 without breaking; reduce motion → 150 ms fades.
- Haptics: `AppHaptics.selection/medium/success/error` only, on outcomes.
- Every widget's doc comment cites its board and frame (`pano 3.1 · kare 2`) and quotes the Turkish copy.
